小提示
1. 传输过程中请保持这个页面在前台，手机不要锁屏。
2. APK 安装时，请在电视上用遥控器确认；如果电视提示「禁止安装未知应用」，按提示允许即可。
3. 文件只走局域网，不会上传到互联网。电视重启前都可以在列表里再次安装或打开。
4. 传输页地址只显示在电视上，请勿分享给不信任的设备。
